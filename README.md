# Mostafa Awaga Portfolio

Personal portfolio website for Mostafa Awaga, a Full Stack .NET Developer focused on ASP.NET Core web applications, RESTful APIs, dashboards, and responsive user interfaces.

Live website: https://mostafahamed.vercel.app/

## Overview

This portfolio presents my background, technical skills, training experience, services, featured projects, and contact information in a responsive single-page website.

## Features

- Responsive portfolio layout for desktop and mobile.
- Hero section with animated role text.
- About, experience, skills, services, projects, and contact sections.
- Featured project cards with links to GitHub repositories.
- Contact form UI with social links.
- Animated background and scroll interactions.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive design

## Run Locally

Open `index.html` in the browser, or run a local static server from the project root.

```bash
npx serve .
```
